# Clipcraft

A free, browser-only text-to-video maker. No server, no API keys.

## Publish on GitHub Pages
1. Create a new repository on github.com (public).
2. Upload `clipcraft.html` and `CLIPCRAFT-README.md` to the repo root.
3. Go to Settings > Pages. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute, your site is live at `https://YOURNAME.github.io/REPO-NAME/clipcraft.html` (rename clipcraft.html to index.html if you want it at the plain repo address).

## Use
Paste a script (one caption per line), choose 9:16 / 1:1 / 4:5 / 16:9, optionally add background images and a handle, then click "Make and download video". Use Chrome or Edge on desktop for best results.
